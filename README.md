# REGISTLESS V0.1

Első Expo MVP teszt.

## Indítás

```bash
npm install
npm start
```

Utána nyisd meg a telefonon az Expo Go appot és szkenneld be a terminálban megjelenő QR-kódot.

## Mi van benne

- Retailer / Client mód
- Manuális regisztráció
- Thumb-zone UI
- Floating SCAN QR gomb
- Client QR
- QR scan
- Egyszerű checkout

## Megjegyzés

Ez még nem tartalmaz OCR-t, PDF számlát vagy WhatsApp megosztást.
